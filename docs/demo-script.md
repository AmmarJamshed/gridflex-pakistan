# Demo script — GRIDFLEX Pakistan

1. Start backend + frontend (see README).
2. Open home → sign in as `utility@gridflex.pk` / `demo1234`.
3. Go to **Simulation** → **RUN PAKISTAN GRIDFLEX SIMULATION**.
4. Show before/after peak reduction and click an evening hour.
5. Open **Market** → run clearing → show zone-constrained settlement + optional hash.
6. Open **Aggregator** → explain 10,000 × 0.5 kW = 5 MW virtual resource.
7. Open **Consumer** → wallet + EV load shift chart.
8. Open **Regulatory** → current facts vs proposed future model.
9. Close with: physical power stays on the grid; the platform settles verified flexibility.
